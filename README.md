# ST-Input 输入助手

SillyTavern 的输入框扩展。结合当前聊天整理草稿，遇到影响结果的歧义时先问你，也可以基于最近一条模型回复生成后续问题。

## 安装

要求 SillyTavern **1.19.0 或更新版本**。在 SillyTavern 的「扩展 → 安装扩展」填入仓库地址：

```text
https://github.com/zyx486013/ST-Input
```

刷新页面后，点击发送框旁的「输入助手」。可直接跟随当前聊天连接，或在「连接设置」选择 ST 已保存的连接配置。

### 在输入助手里配置自定义 API

自定义模式需要配套服务端插件。将仓库的 `server` 目录复制为 **SillyTavern 根目录下的 `plugins/st-input`**，确认其中直接包含 `index.mjs`、`upstream.mjs`、`polish-parameters.mjs` 和 `visible-reasoning.mjs`。在 SillyTavern 的 `config.yaml` 中设置 `enableServerPlugins: true`，然后重启 SillyTavern。更新前端扩展后，手动复制新版服务端文件并重启即可更新服务端插件。

用 ST 管理员账号打开「输入助手 → 连接设置 → 自定义 API」，填入：

- **API 地址**。使用 OpenAI 兼容的 Base URL，例如 `https://api.example.com/v1`。也可以粘贴完整的 `/chat/completions` 地址。
- **API Key**。无需认证时可以留空。已保存的 Key 由服务器在对应 ST 用户的数据目录保存。清除 Key 后点保存即可删除。
- **模型 ID**。手动填写，或点「获取模型」后从输入框的候选项选择。
- **测试连接**。用表单中的地址、Key 和模型发一条固定测试消息。测试后点「保存自定义 API」，正式调用使用已保存的配置。

局域网或 localhost 上的 API 由 **SillyTavern 服务端**访问。在启动 ST 前，用 `ST_INPUT_LOCAL_ORIGINS` 允许具体的本地来源，值写协议、主机和端口。多个来源用逗号分开。如果 ST 运行在 Docker 里，按容器实际能访问的主机名填写。

Linux 示例：

```sh
ST_INPUT_LOCAL_ORIGINS=http://127.0.0.1:1234 node server.js
```

Windows PowerShell 示例：

```powershell
$env:ST_INPUT_LOCAL_ORIGINS = 'http://127.0.0.1:1234'
node server.js
```

扩展里的 API 地址可填 `http://127.0.0.1:1234/v1`。公网地址使用 HTTPS。

## 草稿和上下文

| 操作 | 用法 |
| --- | --- |
| 帮我说清楚 | 根据草稿和上下文给出可编辑的建议，或先提出具体问题 |
| 先问我 | 找出影响结果的歧义，支持点选或填写答案，再合并成最终草稿 |
| 帮我追问 | 根据最后一条模型回复拟写追问，输入框可以留空 |
| 检查回复逻辑 | 检查上一条模型回复的矛盾、论证、适用条件和原问题覆盖 |
| 精修回复 | 用一段文风示范润色上一条模型回复，也可生成无示范稿对照 |

默认读取当前会话最近 8 条可见消息。可以调整消息数、指定一条旧消息作为参考，或关闭聊天上下文。需要参考上一条模型回复的「帮我追问」需开启聊天上下文。

「提示词预览」可查看扩展组装的内容。顺序是系统规则和输出格式、指定参考消息、最近聊天、追问对象（如适用）、草稿、澄清答案、本次任务。用 Chat Completion 时会组装为 `system` 和 `user` 两条消息。ST 使用 Text Completion 时会按其连接或 Instruct 配置转换格式。

「填入输入框」只更新草稿。正式发送时，ST 用主聊天连接和当前预设组装请求。角色卡、世界书和作者注释由 ST 在正式发送时处理。

## 检查回复逻辑

在「输入助手 → 逻辑检查」点击「检查回复逻辑」。结果会标出相关原句、问题说明，以及一条可以直接发送的修正要求。可逐条或全部加入当前草稿，并用「恢复原稿」撤销。开启聊天上下文后，检查会对照原问题和相关前文。关闭上下文时只检查该条回复，涉及外部事实的主张会作为待核验内容提示。

## 分析回复和复用写作指导

在「逻辑检查」里点击「分析上一条回复」检查文风、结构、表达、逻辑和需求覆盖。每条分析会引用原回复、说明具体问题并给出下一条回复可执行的指导。关闭聊天上下文时，只分析该条回复。

点「保存指导」可在当前聊天复用这条建议。在「写作指导」中可将指导或「问题和指导」加入输入框，也可以开启「整理和追问时附到建议草稿」。保存的指导和开关按聊天记录保存，可逐条移除。草稿可继续编辑和手动发送。

## 精修回复

输入助手默认全屏打开，记住上次使用的工具。顶部「小窗口」可切回输入框旁的面板，布局选择会保存。

1. 打开「输入助手 → 精修回复」，选择「无示范」或「有示范」。有示范时，可直接选用已保存的示范，也可选「新建示范」粘贴正文，直接试用。需要复用时填写名称并点「保存示范」。「编辑示范」支持修改或删除已保存的内容。旧版保存的单份示范会迁移为「原文风示范」。
2. 在「修改方式」选择「精修」或「重写」。精修处理局部措辞和句段，重写重新组织整段旁白和对白。切换方式时沿用同一份范文，也保留刚粘贴的内容。按需填写本次要求，再点击「开始精修」或「开始重写」。「提示词预览」可查看请求内容。
3. 左右并排查看文本，删除线标记删改，下划线标记新增。切换修改方式或是否用示范后再生成一次，可以直接对比已经生成的稿件。每份稿件都可以编辑、复制或替换聊天里的原回复。
4. 替换后可以在当前聊天里点击「恢复原回复」。切换聊天会清除这次撤销记录。替换和恢复会更新当前显示的回复版本，并保存到聊天历史。

单份文风示范可保存并发送最多 32,000 字。编辑时会显示字数，超限时保留已粘贴的文字，缩短后即可保存或生成。单阶段请求的素材受 96,000 字符的上限，也会占用模型的上下文额度。使用输入助手的独立「自定义 API」时，超过旧版请求长度限制需要更新配套服务端插件。

选择「有示范」后，可在「本次精修要求」旁点亮「参考范文用词」。它让模型分别参考对白和旁白的修饰疏密和动词选择，并照顾各角色的口吻。首次使用默认关闭，之后记住选择。手写要求可同时使用。

送去精修的原回复、指定参考消息和最近聊天，以及对比用的原回复，都按照当前 SillyTavern 的「改变聊天显示」正则处理。精修时保留 Markdown，恢复原回复时写回原始聊天文本。

重写会保留可识别的首尾状态组件，包括 `<StatusBlock>`、折叠面板、明确标记的代码块状态栏和选项栏。扩展从原始回复保留这些组件，生成完成后按原位置加回。复制、对比或替换时使用正文和应保留的状态组件。

点击「开始重写」会分两次请求。首先从显示正则处理过的原稿提取场景、事件先后、关键细节、人物声线、每轮对白的意思及结尾。接着用剧情记录和所选范文重写完整正文。第二次请求只接收剧情记录、范文和本次要求，记录中的原题及明确锁定的片段按原样写回。换范文后可在「重写设置与记录」单独重跑文风编辑。单阶段请求失败时可从该阶段继续。

「重写设置与记录」还提供「审校后大修」「只查漏洞」和「允许剧情调整」。发现具体漏洞时可生成重排场记。剧情调整方案需逐项确认，默认保留原稿。审校后大修和允许剧情调整可启用「终审并按需返工」。终审发现问题时最多自动返工一轮，按原句定位修改。返工修正了部分或全部问题，且没有引入或加重问题时，更新对比稿。成稿从对比区手动替换。

展开「精修参数」可设置「输出上限（tokens）」。留空时，已保存的连接和当前 Chat Completion 连接会按原稿篇幅和预设自动估算额度。已保存的连接最低为 4096 tokens，自定义 API 留空时使用提供商默认值。输出长度取决于模型支持的额度。手动额度适用于精修和重写，也会更新自定义 Chat Completion 预设中已有的 `max_tokens` 或 `max_completion_tokens`。

同一处的「附加参数」可按 YAML 或 JSON 填写模型支持的参数。例如支持 `max` 的 Chat Completion 服务可输入：

```yaml
reasoning_effort: max
```

附加参数会保存并用于精修和重写。自定义 Chat Completion 连接可填写服务商提供的生成参数，原生 Chat Completion 连接经 SillyTavern 转发常见生成参数。使用输入助手的独立「自定义 API」时，需要更新配套服务端插件以使用手动额度和附加参数。

跟随当前 Chat Completion 连接或使用已保存的 Chat Completion 连接时，精修和重写默认流式接收。生成中的正文显示在「流式预览」里，完整稿收到后进入对比区。中断或达到输出上限时，预览保留已收到的文字，可复制。服务商不兼容流式时，可在「精修参数」里关掉「流式接收」。独立「自定义 API」和 Text Completion 连接使用整包响应。

模型接口返回可见推理或推理摘要时，可以展开「模型思考 · 本次请求」查看。流式请求随接收更新，整包请求在收到响应后显示。对比、复制成稿和替换聊天回复使用正文。独立「自定义 API」需更新配套服务端插件才能读取推理字段。

如果页面显示 Cloudflare 524，表示代理等待响应超时。流式接收需要服务商及时发出数据，且中间代理及时转发。仍超时时，可降低推理强度或通过 SSH 转发访问 SillyTavern。
